 💻 How to Run Java Programs

Step 1: Install JDK on your system.

Step 2: Clone this repository.

bash
git clone https://github.com/SaloniSharma2005/Java-Placement-Preparation.git


Step 3: Navigate to the directory containing the Java file.

Step 4: Compile the Java program.

bash
javac FileName.java


Step 5: Execute the program.

bash
java FileName
